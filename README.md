# SilverMeal Care

고령자의 건강 고민과 식습관 기록을 바탕으로 영양 관리에 참고할 수 있는 점검 결과와 식사 가이드를 제공하는 웹 기반 대시보드입니다.

이 프로젝트는 질병을 진단하거나 치료 식단을 제공하는 서비스가 아니라, 사용자의 식습관을 점검하고 관리 방향을 제안하는 참고용 헬스케어 포트폴리오 프로젝트입니다.

## 현재 구현 범위

- 5가지 관리 카테고리
  - 근육 건강 관리
  - 혈압 관리
  - 혈당 관리
  - 영양 보충 관리
  - 장 건강 관리
- 건강 고민 및 식습관 설문
- 설문 응답 기반 점검 결과 표시
- 식사량, 수분량, 단백질 포함 여부 기록
- 주간 리포트 초안
- 카테고리별 임시 식사 가이드
- 반응형 웹 화면

## 설계 방향

SilverMeal Care는 사용자의 입력을 바탕으로 다음처럼 안내합니다.

- 나쁜 방향: "혈압 위험군입니다."
- 서비스 방향: "짠 음식이나 국물 음식 섭취가 잦게 나타났으니, 혈압 관리에 도움이 될 수 있는 나트륨 섭취 습관을 점검해보세요."

현재 문항과 기준은 개발용 임시 데이터입니다. 식품영양학 파트 조사 자료를 받은 뒤 설문 문항, 점검 기준, 식사 가이드 내용을 근거 기반 문구로 교체할 예정입니다.

## 추후 확장 계획

- 식품영양학 조사 자료 기반 문항/기준/가이드 반영
- 결과가 나온 이유 설명 추가
- 개인 맞춤 식습관 체크리스트 추가
- Supabase 기반 데이터 저장
- Vercel 무료 배포
- 자체 서버 배포, 모니터링, 부하 테스트 기록
